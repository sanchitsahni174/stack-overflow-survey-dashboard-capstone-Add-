
# Stack Overflow Developer Survey Dashboard Capstone

## Project Overview

This capstone project analyzes the Stack Overflow Developer Survey dataset to identify trends in current technology usage, future technology preferences, and developer demographics.

The project was completed as part of my Data Analytics Capstone and includes interactive dashboards created in IBM Cognos Analytics.

View the interactive IBM Cognos dashboard here:

## Dashboard Sections

The dashboard contains three main tabs:

### 1. Current Technology Usage

This section analyzes the technologies developers are currently using, including:

* Top programming languages used
* Top databases used
* Top platforms used
* Top web frameworks used

### 2. Future Technology Trends

This section explores technologies developers want to work with in the future, including:

* Desired programming languages
* Desired databases
* Desired platforms
* Desired web frameworks

### 3. Demographics

This section focuses on respondent demographics, including:

* Age distribution
* Gender distribution
* Education level
* Country or region
* Employment status

## Dataset

The dataset used for this project is based on the Stack Overflow Developer Survey dataset provided as part of the capstone assignment.

File used: `survey_data_updated.csv`

## Key Insights

* Programming languages such as Python, JavaScript, SQL, and HTML/CSS are among the most commonly used by developers.
* Many respondents are interested in learning or working with modern technologies in the future.
* Demographic analysis helps identify patterns across age, gender, education, and employment groups.
* Interactive dashboards make it easier to compare technology usage and future trends.
